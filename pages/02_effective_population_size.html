Effective Population Size

This section describes the estimation of historical and contemporary effective population size (Ne) for the four plateau populations of Millardia kondana. Historical Ne is estimated using PSMC, while contemporary Ne is estimated using GONE.

Software installation

conda activate mkondana_wgs

conda install -c bioconda psmc seqtk -y

GONE is downloaded separately from the official repository and placed in the gone/ directory.

What to expect

  • PSMC and Seqtk available in the conda environment
  • GONE available in the project directory

Input files

  • Cleaned BAM files from Sequence Processing
  • Filtered SNP VCF: variants/variants.filtered.vcf.gz
  • Reference genome: reference/Rrattus.fa

Part I: Historical effective population size (PSMC)

PSMC reconstructs changes in effective population size through time from the distribution of heterozygous sites along a diploid genome.

Step 1: Select high-coverage samples

ls stats/*.mean_coverage.txt

Choose the highest-coverage individuals from each population. These samples provide the most reliable heterozygosity estimates for PSMC.

Example selected samples:

K3
K18
R7
R21
T5
T19
RR4
RR15

What to expect

  • A small set of high-quality individuals
  • These samples will be used for PSMC analysis

Step 2: Generate consensus FASTQ

mkdir -p psmc

bcftools mpileup \
-f reference/Rrattus.fa \
-q 20 -Q 20 \
bam/K3.dedup.bam | \
bcftools call -c | \
vcfutils.pl vcf2fq -d 5 -D 100 > psmc/K3.fq

This converts the mapped BAM file into a diploid consensus FASTQ sequence. Sites with very low coverage (<5) and extremely high coverage (>100) are filtered out.

What to expect

  • psmc/K3.fq
  • A consensus sequence representing the diploid genome

Step 3: Convert FASTQ to PSMC format

fq2psmcfa -q20 psmc/K3.fq > psmc/K3.psmcfa

The consensus FASTQ is converted into the compressed PSMC input format that stores heterozygous and homozygous segments along the genome.

What to expect

  • psmc/K3.psmcfa

Step 4: Run PSMC

psmc -N25 -t15 -r5 -p "4+25*2+4+6" \
-o psmc/K3.psmc \
psmc/K3.psmcfa

This estimates historical effective population size through time for the selected individual.

What to expect

  • psmc/K3.psmc
  • Estimated demographic history for the sample

Step 5: Bootstrap replicates

splitfa psmc/K3.psmcfa > psmc/K3.split.psmcfa

for i in {1..100}
do
  seqtk sample -s$i psmc/K3.split.psmcfa 100 > psmc/bootstrap.$i.psmcfa

  psmc -N25 -t15 -r5 -b -p "4+25*2+4+6" \
  -o psmc/bootstrap.$i.psmc \
  psmc/bootstrap.$i.psmcfa
done

Bootstrap replicates are used to evaluate the stability of the demographic curve by resampling genomic segments.

What to expect

  • 100 bootstrap PSMC files

Step 6: Plot historical Ne

psmc_plot.pl -u 2.5e-8 -g 0.5 psmc/K3 psmc/K3.psmc

The PSMC output is converted into a demographic plot using a mutation rate of 2.5 × 10^-8 per site per generation and a generation time of 0.5 years.

What to expect

  • PDF and PNG demographic plots
  • Historical Ne through time

Part II: Contemporary effective population size (GONE)

GONE estimates recent effective population size from linkage disequilibrium among SNPs within each population.

Step 1: Create population sample lists

grep "Sinhagad" sample_metadata.tsv | cut -f1 > K.list
grep "Rajgad" sample_metadata.tsv | cut -f1 > R.list
grep "Torna" sample_metadata.tsv | cut -f1 > T.list
grep "Raireshwar" sample_metadata.tsv | cut -f1 > RR.list

Each list contains the sample IDs belonging to one population.

What to expect

  • K.list
  • R.list
  • T.list
  • RR.list

Step 2: Extract population-specific VCFs

bcftools view -S K.list variants/variants.filtered.vcf.gz \
-Oz -o variants/K.vcf.gz

bcftools view -S R.list variants/variants.filtered.vcf.gz \
-Oz -o variants/R.vcf.gz

bcftools view -S T.list variants/variants.filtered.vcf.gz \
-Oz -o variants/T.vcf.gz

bcftools view -S RR.list variants/variants.filtered.vcf.gz \
-Oz -o variants/RR.vcf.gz

This creates separate SNP datasets for each plateau population.

What to expect

  • K.vcf.gz
  • R.vcf.gz
  • T.vcf.gz
  • RR.vcf.gz

Step 3: Convert VCF to PLINK format

mkdir -p gone

plink --vcf variants/K.vcf.gz --make-bed --out gone/K
plink --vcf variants/R.vcf.gz --make-bed --out gone/R
plink --vcf variants/T.vcf.gz --make-bed --out gone/T
plink --vcf variants/RR.vcf.gz --make-bed --out gone/RR

GONE requires PLINK binary files as input.

What to expect

  • .bed
  • .bim
  • .fam

Step 4: Run GONE

cd gone

bash script_GONE.sh K
bash script_GONE.sh R
bash script_GONE.sh T
bash script_GONE.sh RR

cd ..

GONE estimates recent effective population size for each population using linkage disequilibrium among SNPs.

What to expect

  • Ne estimates for K, R, T and RR populations
  • Recent demographic trajectories

Final outputs

Historical Ne

  • PSMC plots for selected individuals
  • Bootstrap confidence replicates

Contemporary Ne

  • GONE Ne estimates for K, R, T and RR populations
