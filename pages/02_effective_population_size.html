Effective Population Size

This section estimates both historical and contemporary effective population size (Ne) for the four plateau populations of Millardia kondana.

Biological Rationale

The four plateau systems (Sinhagad, Rajgad, Torna and Raireshwar) are geographically isolated. Historical isolation, habitat fragmentation and small population size may have caused demographic decline, reduced gene flow and increased inbreeding.

Two complementary approaches are used:

  • PSMC — historical Ne through time from whole-genome heterozygosity of single individuals.
  • GONE — contemporary Ne from linkage disequilibrium among SNPs within each population.

Input Files

  • Cleaned BAM files from Sequence Processing
  • Filtered SNP VCF
  • Reference genome: Rrattus.fa

Part I — Historical Ne (PSMC)

Sample Selection

PSMC performs best with high-quality, relatively high-coverage genomes. Select the two highest-coverage individuals from each plateau.

Generate Consensus FASTQ

Create a script: scripts/02_effective_population_size/psmc_consensus.sh

#!/bin/bash

SAMPLE=$1

bcftools mpileup \
-f reference/Rrattus.fa \
-q 20 -Q 20 \
bam/${SAMPLE}.dedup.bam | \
bcftools call -c | \
vcfutils.pl vcf2fq -d 5 -D 100 > psmc/${SAMPLE}.fq

Run for each selected sample:

mkdir -p psmc

bash scripts/02_effective_population_size/psmc_consensus.sh SIN_03

Convert to PSMCFA

fq2psmcfa -q20 psmc/SIN_03.fq > psmc/SIN_03.psmcfa

Run PSMC

psmc -N25 -t15 -r5 -p "4+25*2+4+6" \
-o psmc/SIN_03.psmc \
psmc/SIN_03.psmcfa

Repeat for all selected individuals.

Bootstrap Replicates

splitfa psmc/SIN_03.psmcfa > psmc/SIN_03.split.psmcfa

for i in {1..100}
do
  seqtk sample -s$i psmc/SIN_03.split.psmcfa 100 > psmc/bootstrap.$i.psmcfa

  psmc -N25 -t15 -r5 -b -p "4+25*2+4+6" \
  -o psmc/bootstrap.$i.psmc \
  psmc/bootstrap.$i.psmcfa
done

Plot Historical Ne

psmc_plot.pl -u 2.5e-8 -g 0.5 psmc/SIN_03 psmc/SIN_03.psmc

Assumptions

  • Mutation rate: 2.5 × 10^-8 per site per generation
  • Generation time: 0.5 years

Interpretation

  • Recent decline → sharp drop toward present.
  • Long-term small population → persistently low Ne.
  • Similar curves among plateaus → shared demographic history.
  • Divergent curves → population-specific demographic events.

Part II — Current Ne (GONE)

Current Ne is estimated separately for each plateau population.

Create Population-Specific Sample Lists

grep "Sinhagad" sample_metadata.tsv | cut -f1 > SIN.list
grep "Rajgad"   sample_metadata.tsv | cut -f1 > RAJ.list
grep "Torna"    sample_metadata.tsv | cut -f1 > TOR.list
grep "Raireshwar" sample_metadata.tsv | cut -f1 > RAI.list

Extract Population VCFs

bcftools view -S SIN.list variants/variants.filtered.vcf.gz \
-Oz -o variants/SIN.vcf.gz

bcftools view -S RAJ.list variants/variants.filtered.vcf.gz \
-Oz -o variants/RAJ.vcf.gz

bcftools view -S TOR.list variants/variants.filtered.vcf.gz \
-Oz -o variants/TOR.vcf.gz

bcftools view -S RAI.list variants/variants.filtered.vcf.gz \
-Oz -o variants/RAI.vcf.gz

Convert to PLINK Format

plink --vcf variants/SIN.vcf.gz --make-bed --out gone/SIN
plink --vcf variants/RAJ.vcf.gz --make-bed --out gone/RAJ
plink --vcf variants/TOR.vcf.gz --make-bed --out gone/TOR
plink --vcf variants/RAI.vcf.gz --make-bed --out gone/RAI

Run GONE

mkdir -p gone/results

cd gone

cp SIN.bed INPUT_FILES/
cp SIN.bim INPUT_FILES/
cp SIN.fam INPUT_FILES/

bash script_GONE.sh SIN

Repeat for RAJ, TOR and RAI.

Output Files

gone/results/SIN_Ne.txt
gone/results/RAJ_Ne.txt
gone/results/TOR_Ne.txt
gone/results/RAI_Ne.txt

Interpretation

  • Ne < 50 → severe recent reduction.
  • Ne 50–200 → moderate concern.
  • Ne > 200 → relatively larger contemporary population.
