Sequence Processing

This section describes the preprocessing workflow for Illumina whole-genome resequencing data. The goal is to convert raw paired-end FASTQ files into high-quality, duplicate-marked and indexed BAM files suitable for population genomic analyses.

Biological Context

The pipeline is designed for Millardia kondana, a non-model rodent without a species-specific reference genome. Reads are aligned to the Rattus rattus reference genome, which is used as a surrogate reference for downstream analyses.

Input Data

  • Illumina paired-end whole-genome sequencing
  • ~36 GB data requested per sample
  • 40 M. kondana individuals from four plateau populations
  • 10 M. meltada individuals for diversity comparison

Step 1: Quality Assessment

Run FastQC on all raw FASTQ files.

mkdir -p fastqc_raw

fastqc raw_fastq/*.fastq.gz \
-o fastqc_raw \
-t 16

Summarize with MultiQC

multiqc fastqc_raw \
-o multiqc_raw

Step 2: Adapter and Quality Trimming

Trim adapters and low-quality bases using fastp.

mkdir -p trimmed

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  fastp \
    -i raw_fastq/${sample}_R1.fastq.gz \
    -I raw_fastq/${sample}_R2.fastq.gz \
    -o trimmed/${sample}_R1.trim.fastq.gz \
    -O trimmed/${sample}_R2.trim.fastq.gz \
    -h trimmed/${sample}.html \
    -j trimmed/${sample}.json \
    --detect_adapter_for_pe \
    --thread 16
done

Step 3: Quality Check After Trimming

mkdir -p fastqc_trimmed

fastqc trimmed/*.fastq.gz \
-o fastqc_trimmed \
-t 16

multiqc fastqc_trimmed \
-o multiqc_trimmed

Step 4: Download Reference Genome

Create the reference directory.

mkdir -p reference
cd reference

Place the Rattus rattus reference genome as:

Rrattus.fa

Step 5: Index the Reference

BWA

bwa-mem2 index Rrattus.fa

SAMtools

samtools faidx Rrattus.fa

Picard

picard CreateSequenceDictionary \
R=Rrattus.fa \
O=Rrattus.dict

Step 6: Align Reads

mkdir -p alignment

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  bwa-mem2 mem \
    -t 16 \
    reference/Rrattus.fa \
    trimmed/${sample}_R1.trim.fastq.gz \
    trimmed/${sample}_R2.trim.fastq.gz \
    > alignment/${sample}.sam
done

Step 7: Convert and Sort BAM

mkdir -p bam

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools sort \
    -@ 16 \
    -o bam/${sample}.sorted.bam \
    alignment/${sample}.sam

  samtools index bam/${sample}.sorted.bam
done

Step 8: Mark PCR Duplicates

mkdir -p stats

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  picard MarkDuplicates \
    I=bam/${sample}.sorted.bam \
    O=bam/${sample}.dedup.bam \
    M=stats/${sample}.dup_metrics.txt \
    REMOVE_DUPLICATES=false

  samtools index bam/${sample}.dedup.bam
done

Step 9: Alignment Statistics

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools flagstat \
    bam/${sample}.dedup.bam \
    > stats/${sample}.flagstat

  samtools stats \
    bam/${sample}.dedup.bam \
    > stats/${sample}.stats
done

Step 10: Coverage Estimation

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools depth -a bam/${sample}.dedup.bam | \
  awk '{sum+=$3} END {print sum/NR}' \
  > stats/${sample}.mean_coverage.txt
done

Duplicate rate <20%
