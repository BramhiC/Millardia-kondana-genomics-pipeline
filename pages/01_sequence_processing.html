Sequence Processing

This section describes the preprocessing workflow used for Illumina paired-end whole-genome sequencing data of Millardia kondana and Millardia meltada. The final outputs are cleaned, duplicate-marked BAM files and a filtered SNP dataset for downstream analyses.

Input data

  • K1–K25: Sinhagad
  • R1–R25: Rajgad
  • T1–T25: Torna
  • RR1–RR20: Raireshwar
  • MEL1–MEL10: Millardia meltada

Each sample contains paired-end FASTQ files.

K1_R1.fastq.gz
K1_R2.fastq.gz

Software installation

conda create -n mkondana_wgs -y
conda activate mkondana_wgs

conda install -c bioconda fastqc multiqc fastp bwa-mem2 samtools bcftools gatk4 plink -y

This creates a dedicated conda environment and installs all software required for quality control, trimming, read mapping, duplicate marking and variant calling.

Step 1: Create sample metadata

cat > sample_metadata.tsv << EOF
sample	population	species
K1	Sinhagad	M_kondana
K2	Sinhagad	M_kondana
R1	Rajgad	M_kondana
T1	Torna	M_kondana
RR1	Raireshwar	M_kondana
MEL1	Meltada	M_meltada
EOF

This file stores the sample name, population and species information and is used by several downstream scripts.

What to expect

  • sample_metadata.tsv

Step 2: Quality check of raw reads

mkdir -p fastqc_raw

fastqc raw_fastq/*.fastq.gz \
-o fastqc_raw \
-t 16

multiqc fastqc_raw -o multiqc_raw

FastQC examines read quality, adapter contamination, GC content and other sequencing metrics. MultiQC combines all FastQC reports into a single summary.

What to expect

  • One FastQC report per FASTQ file
  • A combined MultiQC report
  • Identification of adapter contamination or low-quality regions

Step 3: Adapter and quality trimming

mkdir -p trimmed

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  fastp \
    -i raw_fastq/${sample}_R1.fastq.gz \
    -I raw_fastq/${sample}_R2.fastq.gz \
    -o trimmed/${sample}_R1.trim.fastq.gz \
    -O trimmed/${sample}_R2.trim.fastq.gz \
    -h trimmed/${sample}.html \
    -j trimmed/${sample}.json \
    --detect_adapter_for_pe \
    --thread 16
done

This script removes Illumina adapter sequences and trims low-quality bases from both paired-end reads.

What to expect

  • Trimmed paired FASTQ files
  • One HTML report per sample
  • Reduced adapter contamination
  • Improved overall read quality

Step 4: Quality check after trimming

mkdir -p fastqc_trimmed

fastqc trimmed/*.fastq.gz \
-o fastqc_trimmed \
-t 16

multiqc fastqc_trimmed -o multiqc_trimmed

This confirms that trimming improved read quality and removed most adapter contamination.

What to expect

  • Improved per-base quality scores
  • Minimal adapter warnings

Step 5: Prepare the reference genome

mkdir -p reference
cd reference

# Place Rrattus.fa in this directory

bwa-mem2 index Rrattus.fa

samtools faidx Rrattus.fa

gatk CreateSequenceDictionary \
-R Rrattus.fa \
-O Rrattus.dict

cd ..

The Rattus rattus reference genome is indexed for BWA, SAMtools and GATK.

What to expect

  • BWA index files
  • Rrattus.fa.fai
  • Rrattus.dict

Step 6: Read mapping

mkdir -p alignment

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  bwa-mem2 mem \
    -t 16 \
    reference/Rrattus.fa \
    trimmed/${sample}_R1.trim.fastq.gz \
    trimmed/${sample}_R2.trim.fastq.gz \
    > alignment/${sample}.sam
done

Trimmed reads are aligned to the reference genome to determine their genomic positions.

What to expect

  • One SAM file per sample
  • Mapping rates typically above ~80%

Step 7: Convert and sort BAM files

mkdir -p bam

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools sort \
    -@ 16 \
    -o bam/${sample}.sorted.bam \
    alignment/${sample}.sam

  samtools index bam/${sample}.sorted.bam
done

SAM files are converted into compressed BAM format and sorted by genomic position.

What to expect

  • Sorted BAM file
  • BAM index file

Step 8: Mark PCR duplicates

mkdir -p stats

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  gatk MarkDuplicates \
    -I bam/${sample}.sorted.bam \
    -O bam/${sample}.dedup.bam \
    -M stats/${sample}.dup_metrics.txt

  samtools index bam/${sample}.dedup.bam
done

PCR duplicates are marked so that they do not bias variant calling.

What to expect

  • Duplicate-marked BAM file
  • Duplicate metrics file
  • Indexed BAM file

Step 9: Alignment statistics

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools flagstat bam/${sample}.dedup.bam \
    > stats/${sample}.flagstat

  samtools stats bam/${sample}.dedup.bam \
    > stats/${sample}.stats
done

These statistics are used to evaluate mapping quality, properly paired reads and duplicate levels.

What to expect

  • Flagstat summary per sample
  • Detailed alignment statistics per sample

Step 10: Mean coverage estimation

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools depth -a bam/${sample}.dedup.bam | \
  awk '{sum+=$3} END {print sum/NR}' \
  > stats/${sample}.mean_coverage.txt
done

Mean sequencing depth is calculated for each sample.

What to expect

  • One mean coverage file per sample

Step 11: Create BAM list

ls bam/*.dedup.bam > bamlist.txt

This file contains the paths to all cleaned BAM files and is used for joint variant calling.

What to expect

  • bamlist.txt

Step 12: Joint variant calling

mkdir -p variants

bcftools mpileup \
-f reference/Rrattus.fa \
-b bamlist.txt \
-Ou \
-q 20 \
-Q 20 \
-a AD,DP | \
bcftools call \
-m -v -Oz \
-o variants/variants.raw.vcf.gz

bcftools index variants/variants.raw.vcf.gz

Variants are called jointly across all samples to identify shared and population-specific variants consistently.

What to expect

  • Raw VCF containing SNPs and INDELs
  • Indexed compressed VCF

Step 13: Retain SNPs only

bcftools view -v snps \
variants/variants.raw.vcf.gz \
-Oz -o variants/variants.snps.vcf.gz

INDELs are removed because downstream analyses in this pipeline use SNPs.

What to expect

  • SNP-only VCF

Step 14: Filter by variant quality

bcftools filter -i 'QUAL>20' \
variants/variants.snps.vcf.gz \
-Oz -o variants/variants.qual20.vcf.gz

Low-confidence variants are removed using a minimum QUAL score of 20.

What to expect

  • Reduced number of low-quality variants

Step 15: Remove rare variants (MAC > 3)

bcftools view -i 'MAC>3' \
variants/variants.qual20.vcf.gz \
-Oz -o variants/variants.mac3.vcf.gz

Variants with very low allele counts are removed to reduce noise in population structure analyses.

What to expect

  • More reliable SNP set

Step 16: Hardy–Weinberg filtering

bcftools +fill-tags variants/variants.mac3.vcf.gz -- -t HWE | \
bcftools view -i 'HWE>0.05' \
-Oz -o variants/variants.filtered.vcf.gz

bcftools index variants/variants.filtered.vcf.gz

Variants showing strong deviation from Hardy–Weinberg equilibrium are removed.

What to expect

  • Final filtered SNP dataset
  • Indexed compressed VCF

Final outputs

Cleaned BAM files

bam/K1.dedup.bam
bam/K1.dedup.bam.bai

Filtered SNP dataset

variants/variants.filtered.vcf.gz
variants/variants.filtered.vcf.gz.csi

The BAM files are used for ANGSD, ROHan and PSMC. The filtered VCF is used for PCAngsd, NGSadmix, FEIMS and GONE.
