Sequence Processing

This section describes the preprocessing workflow for Illumina whole-genome resequencing data of Millardia kondana and Millardia meltada. The objective is to generate high-quality, duplicate-marked and indexed BAM files and a filtered SNP dataset for downstream population genomic analyses.

Reference Genome

Because M. kondana does not currently have a species-specific reference genome, reads are aligned to the Rattus rattus reference genome.

Input Data

  • Illumina paired-end whole-genome sequencing
  • ~36 GB requested per sample
  • 40 M. kondana individuals
  • 10 M. meltada individuals

Step 1: Quality Assessment

Run FastQC on all raw FASTQ files.

mkdir -p fastqc_raw

fastqc raw_fastq/*.fastq.gz \
-o fastqc_raw \
-t 16

Summarize Reports

multiqc fastqc_raw \
-o multiqc_raw

Step 2: Adapter and Quality Trimming

Trim adapters and low-quality bases using fastp.

mkdir -p trimmed

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  fastp \
    -i raw_fastq/${sample}_R1.fastq.gz \
    -I raw_fastq/${sample}_R2.fastq.gz \
    -o trimmed/${sample}_R1.trim.fastq.gz \
    -O trimmed/${sample}_R2.trim.fastq.gz \
    -h trimmed/${sample}.html \
    -j trimmed/${sample}.json \
    --detect_adapter_for_pe \
    --thread 16
done

Step 3: Quality Check After Trimming

mkdir -p fastqc_trimmed

fastqc trimmed/*.fastq.gz \
-o fastqc_trimmed \
-t 16

multiqc fastqc_trimmed \
-o multiqc_trimmed

Step 4: Prepare Reference Genome

mkdir -p reference
cd reference

Place the Rattus rattus reference genome as:

Rrattus.fa

Index for BWA

bwa-mem2 index Rrattus.fa

Index for SAMtools

samtools faidx Rrattus.fa

Create Sequence Dictionary

gatk CreateSequenceDictionary \
-R Rrattus.fa \
-O Rrattus.dict

Step 5: Align Reads

mkdir -p alignment

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  bwa-mem2 mem \
    -t 16 \
    reference/Rrattus.fa \
    trimmed/${sample}_R1.trim.fastq.gz \
    trimmed/${sample}_R2.trim.fastq.gz \
    > alignment/${sample}.sam
done

Step 6: Convert and Sort BAM

mkdir -p bam

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools sort \
    -@ 16 \
    -o bam/${sample}.sorted.bam \
    alignment/${sample}.sam

  samtools index bam/${sample}.sorted.bam
done

Step 7: Mark PCR Duplicates

Duplicates are marked, not removed.

mkdir -p stats

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  gatk MarkDuplicates \
    -I bam/${sample}.sorted.bam \
    -O bam/${sample}.dedup.bam \
    -M stats/${sample}.dup_metrics.txt

  samtools index bam/${sample}.dedup.bam
done

Step 8: Alignment Statistics

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools flagstat \
    bam/${sample}.dedup.bam \
    > stats/${sample}.flagstat

  samtools stats \
    bam/${sample}.dedup.bam \
    > stats/${sample}.stats
done

Step 9: Mean Coverage Estimation

for sample in $(cut -f1 sample_metadata.tsv | tail -n +2)
do
  samtools depth -a bam/${sample}.dedup.bam | \
  awk '{sum+=$3} END {print sum/NR}' \
  > stats/${sample}.mean_coverage.txt
done

Variant Calling

Create BAM List

ls bam/*.dedup.bam > bamlist.txt

Generate Raw BCF

mkdir -p variants

bcftools mpileup \
-f reference/Rrattus.fa \
-b bamlist.txt \
-Ou \
-q 20 \
-Q 20 \
-a AD,DP \
| bcftools call \
-m -v -Ou \
| bcftools norm -f reference/Rrattus.fa -Oz \
-o variants/variants.raw.vcf.gz

bcftools index variants/variants.raw.vcf.gz

Variant Filtering

Retain SNPs Only

bcftools view -v snps \
variants/variants.raw.vcf.gz \
-Oz -o variants/variants.snps.vcf.gz

Filter by Quality

bcftools filter -i 'QUAL>20' \
variants/variants.snps.vcf.gz \
-Oz -o variants/variants.qual20.vcf.gz

Remove Rare Variants (MAC > 3)

bcftools view -i 'MAC>3' \
variants/variants.qual20.vcf.gz \
-Oz -o variants/variants.mac3.vcf.gz

Hardy-Weinberg Filtering

bcftools +fill-tags variants/variants.mac3.vcf.gz -- -t HWE | \
bcftools view -i 'HWE>0.05' \
-Oz -o variants/variants.filtered.vcf.gz

bcftools index variants/variants.filtered.vcf.gz

Final Outputs

  • 50 cleaned BAM files
  • 50 BAM index files
  • variants/variants.filtered.vcf.gz
  • variants/variants.filtered.vcf.gz.csi
